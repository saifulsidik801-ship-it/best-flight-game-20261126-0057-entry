A golden-hour 3D flight game: fly the bush plane Kestrel-9 through glowing rings over a volcanic valley, drop supplies along the river, and land on a lit strip at dusk. Three.js chase and cockpit cameras, a lit HUD with altitude, speed, heading and a live attitude indicator, fuel and airframe management, wind gusts and volcano thermals — all in static files, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080 — W/S throttle, arrow keys to fly, C camera, P pause
```
